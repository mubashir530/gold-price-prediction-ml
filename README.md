# 🪙 Gold Price Prediction using Machine Learning

An end-to-end Machine Learning project to forecast gold prices based on financial indicators, stock market trends, and historical price data. This project implements a **Linear Regression** model to analyze linear relationships and predict future trends with precision.

---

## 📊 Key Highlights & Results
- **Model:** Linear Regression
- **Evaluation Metrics:** $R^2$ Score, Mean Absolute Error (MAE), Root Mean Squared Error (RMSE)
- **Key Outcome:** Achieved strong baseline performance by modeling price trends and feature dependencies efficiently.

---

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / VS Code

---

## 📈 ML Workflow
1. **Data Cleaning & Preprocessing:** Handling missing values, scaling features, and converting date/time attributes.
2. **Exploratory Data Analysis (EDA):** Visualizing correlation matrices, trends over time, and distribution of gold prices.
3. **Model Training:** Splitting dataset into training and testing sets to evaluate Linear Regression performance.
4. **Model Evaluation:** Analyzing prediction errors and regression metrics to test model accuracy.
